🛒 MERN Stack E-Commerce Web Application
A fully responsive, feature-rich full-stack e-commerce web application built with modern web technologies. Designed for seamless online shopping, it features robust user authentication, dynamic product filtering across multiple categories, an interactive shopping cart, and a polished UI with smooth animations.

🚀 Key Features
User Authentication: Secure user registration and login utilizing JSON Web Tokens (JWT) and encrypted passwords.

Product Catalog & Search: Browse through 30+ categorized products (Electronics, Fashion, Footwear, Accessories, Home, & Fitness) with real-time keyword search and instant category filtering.

Interactive Shopping Cart: Add, update, and manage items seamlessly with state synchronization between local storage and the backend MongoDB database.

Modern UI/UX: Styled with Tailwind CSS / custom responsive design featuring immersive shopping backgrounds, cards, and smooth transition animations.

Database Seeding: Automated database seeder script to populate and manage sample inventory with high-resolution images.

🛠️ Technologies Used
Frontend
React.js (Vite) – Component-based UI architecture

React Router DOM – Client-side multi-page routing and navigation

Axios – HTTP client for RESTful API communication

CSS3 / Responsive Styling – Custom layouts, gradients, and animations

Backend
Node.js – JavaScript runtime environment

Express.js – Fast, unopinionated web framework for building REST APIs

JSON Web Tokens (JWT) & bcryptjs – Secure user authentication and password hashing

Database & Deployment
MongoDB Atlas – Cloud NoSQL database hosting collections for users, products, and carts

Mongoose – ODM library for schema modeling and data validation

Vercel / Render – Cloud deployment platforms
